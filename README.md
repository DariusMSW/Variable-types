# Variable-types
Von Darius & Tobias

Interaktive Lernwebsite (Deutsch) zu den Variablentypen in C mit fester Grösse – `uint8_t` bis `int64_t` aus `stdint.h` sowie `float32_t`/`float64_t` – von den Grundlagen über Wertebereiche, Bits und Kommazahlen bis zu struct-Padding.

## Starten
`index.html` per Doppelklick im Browser öffnen – fertig. Es braucht keinen Server, keine Installation und kein Internet. Der Fortschritt wird lokal im Browser (localStorage) gespeichert und kann auf der Startseite zurückgesetzt werden.

Neue Aufgaben werden in `js/tasks.js` als Daten ergänzt (Aufgabentypen sind oben in der Datei beschrieben).
